## Editorial Policy

- ใช้ official documentation เป็นแหล่งอ้างอิงเรื่อง version และ behavior
- หนังสือหรือบทเรียนรุ่นเก่าใช้ได้เฉพาะแนวคิดพื้นฐานที่ยังไม่เปลี่ยน เช่น relational design, keys และ SQL fundamentals
- ห้ามยืนยันว่า feature รองรับในรุ่นปัจจุบันโดยอาศัยหนังสือเก่าเพียงอย่างเดียว
- ไม่คัดลอกข้อความหรือ code จำนวนมากจากหนังสือที่มีลิขสิทธิ์
- ตัวอย่างใน repository ต้องเขียนใหม่ ทดสอบได้ และระบุ teaching baseline
